## Overview

This project involved transforming the Astro Cactus template into a fully customized, professional cybersecurity portfolio. 

## Key Features

- **Terminal Aesthetic**: Custom monospace typography and terminal blocks
- **Dark/Light Mode**: Full support with custom Oklch color palettes
- **Content Collections**: Type-safe markdown rendering for posts, projects, and series.
