# Ascend-X.dev | Cybersecurity Portfolio

The personal portfolio and technical blog of Nandakishore V, a Penetration Tester, Cloud Security Engineer, and avid CTF competitor.

## Tech Stack
- [Astro](https://astro.build/) - Framework
- [Tailwind CSS](https://tailwindcss.com/) - Styling
- [TypeScript](https://www.typescriptlang.org/) - Logic

## Running Locally

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

## Features
- SEO Optimized with JSON-LD structured data
- Interactive Terminal Easter Egg (`Ctrl + ~`)
- Client-side secured Admin Portal
- Markdown/MDX Blog with full syntax highlighting
- 100/100 Lighthouse Performance Score
